# GG Studio releases

Updates for **GG Studio**, an After Effects panel for gameplay and TikTok creators, by NOME.

GG Studio checks `latest.json` here when it starts. When there's a newer version, the panel shows **Update**. Click it, restart After Effects, and you're up to date. You still need your licence key from your Gumroad receipt.

Get GG Studio (Monthly, Yearly or Lifetime): https://proq8er.gumroad.com/l/ggstudio

**Download the latest installer:** [GG-Studio-Setup.exe](https://raw.githubusercontent.com/Abdullahpronet/ggstudio-releases/main/latest/GG-Studio-Setup.exe)
