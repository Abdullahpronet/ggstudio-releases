# GG Studio 0.8.3

- **Fixed: some DLSS 5 game presets stopped right away.** Valorant, Call of Duty, Warzone, CS2, GTA V and Rainbow Six Siege could stop at the start of a render with no message. They now render on every quality. GG Studio also keeps every setting inside the range Visual Enhancer accepts, so this can't happen again.
- **Works with Visual Enhancer v20.** v20 keeps its video tools in a new place. GG Studio now finds them there, so "only the selected part" trims work again and the whole clip isn't sent.
