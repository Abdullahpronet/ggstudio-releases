# GG Studio 0.8.14

- **Updates no longer need an After Effects restart.** Click **Update** and GG Studio installs the new version straight into the open panel, then reloads itself after a moment. Only the files that changed are written, and a copy of the old files is kept, so an update that can't finish leaves the panel exactly as it was.
- If a file is busy (for example an antivirus scan), nothing is changed and the update installs the next time After Effects closes, like before.
- **Getting this version** still uses the old way once: after clicking Update, close After Effects and open it again. Every update after 0.8.14 installs without a restart.
