# GG Studio 0.9.3

- **Harder to tamper with.** GG Studio now checks its own files every time it starts: its code must match the official version signed by NOME. A copy whose files were changed, or that isn't the signed GG Studio, stops and asks to be reinstalled from the official installer.
- GG Studio's code is now scrambled, so the licence and demo checks are much harder to find and change.
- Buyers and demo users see no change. If GG Studio ever says its files don't match, reinstall it with the installer from the GG Studio page; your key and settings are kept.
