# GG Studio 0.9.2

- **The free 2-day demo is now checked online.** GG Studio's demo server remembers when each PC started its demo, using the server's own clock. Reinstalling GG Studio or Windows, deleting files, using another Windows account or changing the clock doesn't give a new demo.
- **Starting the demo needs the internet** (once). After that the demo keeps working offline until its 2 days are up.
- **Time left follows the server's clock**, so the countdown in the panel is right even if the PC's clock is wrong.
- Only anonymous, scrambled PC ids are sent, never names or serial numbers.
- Buyers with a key see no change.
