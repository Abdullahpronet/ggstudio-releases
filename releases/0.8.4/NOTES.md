# GG Studio 0.8.4

- **"4K · 120 FPS" is much faster on 120 fps clips.** If your clip is already 120 fps, Frame Generation is skipped instead of doubling it to 240 fps. A 16-second Call of Duty clip now takes roughly 35–40 minutes instead of more than 2 hours. Clips below 120 fps still get Frame Generation.
- **Know how long a render will take.** Before a long render, GG Studio says about how long it will take and suggests a faster option. While it renders, the progress line shows the time so far against that estimate.
