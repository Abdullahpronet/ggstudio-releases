# GG Studio 0.10.6

- **Your key stays with your computer.** A licence key now works on 2 computers, and a computer that already uses the key always gets back in: removing the key, logging out, reinstalling GG Studio or reinstalling Windows on the same PC never uses up a slot again.
- **One key for GG Studio and NOME 60.** The same key unlocks both apps; one PC counts once, whichever apps it runs.
- If you were told "This key is already active on 2 computers" after removing your key, update to 0.10.6 and enter the key again.
