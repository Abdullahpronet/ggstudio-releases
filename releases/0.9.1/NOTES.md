# GG Studio 0.9.1

- **One free demo per PC, for real.** The 2-day demo is now recorded for the whole computer, so a second Windows account on the same PC doesn't get a new one. Reinstalling, deleting files or changing the clock doesn't give more time either.
- Once a licence key has worked on a computer, that computer doesn't get the free demo later (for example after removing the key).
- The demo bar re-checks the demo every 10 minutes while the panel is open.
- Buyers with a key see no change.
