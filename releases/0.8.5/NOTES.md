# GG Studio 0.8.5

- **DLSS 5 GG Booster game presets are about 3× faster.** Colour and sharpening now run before the 4K upscale instead of on the big 4K frames. Colour is the same, and sharpening is set stronger so the result is just as crisp. On an RTX 5070, a 16-second Call of Duty 4K clip now takes about 5 minutes (it was about 15).
- **Much smaller files.** The default export quality is now "Best" instead of "Max": files are about 30× smaller (around 250 MB instead of 8 GB for 16 s of 4K at 120 fps), and render time is the same. You can still pick Max.
- **More accurate time estimates**, based on timed test renders.
- Settings saved by older versions update themselves the first time you open the DLSS tab.
